网站：[asd14776738.github.io/food-campus-2027](https://asd14776738.github.io/food-campus-2027/) · [自动更新运行记录](https://github.com/asd14776738/food-campus-2027/actions)

在线部署：GitHub Pages。源项目更新后，已打开的网页每分钟直接检查一次；GitHub Actions 每5分钟计划重新构建并发布最新数据快照。GitHub调度、网络缓存和上游人工维护可能造成延迟，不保证秒级更新。在线服务不依赖本地电脑开机。

在线与本地的个人记录按浏览器网站地址分别保存。迁移时在本地“导出备份”，再到在线网站“恢复备份”。任何个人进度均不会写入GitHub仓库。

### GitHub Pages 部署

仓库 Settings → Pages → Build and deployment 选择 GitHub Actions。工作流 `.github/workflows/pages.yml` 在推送到 main、手动运行或每5分钟计划执行时，先测试数据可靠性，再获取最新数据、构建 `dist/` 并部署。失败会保留之前成功发布的网站。

本地验证静态导出：`python build_site.py --refresh`。`dist/` 可部署到任何静态托管平台；资源使用相对路径，可在项目子路径下运行。浏览器在线更新失败时自动使用部署快照，并展示失败提示。`verify_cloud.cjs` 可使用环境变量 `PLAYWRIGHT_MODULE`、`BROWSER_EXECUTABLE` 和 `SITE_URL` 验证静态站点。

本地地址：**http://127.0.0.1:2027**

## 使用

双击 `打开食品校招.cmd`。已经运行时只打开网站；未运行时在后台启动服务。只监听本机，不发布到公网。无需安装 npm 包、数据库或 API 密钥，需要本机 Python 3.10+。

已在当前 Windows 用户的登录启动目录安装 `FoodCampus2027.lnk`，登录后隐藏启动，不自动弹出浏览器。

网站提供：

- 食品制造、乳业饮品、粮油调味、餐饮茶饮、食品零售筛选。
- 搜索企业、岗位和公告描述；以空格分隔多个关键词时同时匹配。
- 研发品控、生产工艺、供应链采购、市场销售、管培生筛选。
- 企业详情、招聘链接、公众号或邮箱等完整投递方式、原始信息来源。
- 收藏、投递状态、每次状态变更日期、个人备注。
- JSON备份与恢复；按当前筛选结果导出Excel可打开的UTF-8 CSV。

## 每日更新

1. Codex 自动任务“食品行业2027校招每日更新”已设为每天 **09:00（Asia/Shanghai）** 运行 `update.ps1`。有新增、重要变化或失败才通知。任务需要 Codex 能运行且电脑开机联网。
2. 本地 Python 服务独立运行时每天检查并同步一次，启动时补检；失败每小时重试。即使关闭网页，也不会停止服务。关闭 Codex 后，本地服务仍可自行同步。
3. 点击网页“立即更新”可随时同步。更新后的数据一分钟内自动反映到已打开的网页。

电脑关机或休眠期间不能联网同步；下次登录启动后会补检。网页底部区分上游更新日期、本地同步时间和失败状态。网络失败、空数据或格式异常会保留最后一份有效数据，不会用空列表覆盖。

手工运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start.ps1 -NoBrowser
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\update.ps1
```

## 来源与范围

数据来自用户指定项目：[xinyangli-326/2027qiuzhao](https://github.com/xinyangli-326/2027qiuzhao)，程序读取其 `main/data.json`。本网站重新实现界面和本地同步服务，未复制原项目界面代码。

筛选使用 `server.py` 中的 `GROUPS` 企业名称规则、明确食品行业分类及有限的食品业务关键词。没有把整个“快消”分类都视为食品行业，排除了宝洁、蓝月亮、日化、文具、电子等非食品企业。农牧原料、食品供应链、酒饮和综合食品集团纳入范围；综合集团的具体岗位不一定全部属于食品业务。

**上游收录不是独立核验，也不表示目前仍在招聘。** 开启时间来自上游，不是投递截止时间。岗位匹配仅依据原始岗位文本，不编造专业、地点、薪资或截止日期。缺失的原始公告来源会明确标注。上游维护频率决定新信息覆盖范围，自动同步不能保证覆盖全国所有校招。

## 个人数据

投递进度、收藏、备注仅在浏览器 `localStorage` 中保存，不上传至服务器、GitHub或其他平台。始终使用同一个地址 `http://127.0.0.1:2027` 和同一个浏览器。使用 `localhost`、更换浏览器、无痕模式或清除网站数据不会共享进度。

请定期“导出备份”。“恢复备份”合并记录；同一企业以备份中的记录为准。只有符合格式的备份才会导入。数据更新不清除个人记录。企业按名称生成稳定ID；若上游改变企业名称，其记录可能成为新企业，旧进度仍保存在备份中。

## 文件

- `server.py`：HTTP服务、食品企业识别、同步、每日补检。
- `public/`：网站静态界面，无外部CDN依赖。
- `upstream.json`：最近成功取得的原始数据。
- `data.json`：食品行业数据快照。
- `sync-status.json`：最近一次同步结果。
- `server.log` / `server-error.log`：启动输出与访问日志。
- `start.ps1` / `update.ps1`：启动和更新入口。
- `install-startup.ps1`：重新安装当前用户登录启动快捷方式。
- `test_server.py` / `verify_cloud.cjs`：数据可靠性测试与静态站点浏览器验证脚本。

## 故障处理与停止

- 地址无法打开：双击 `打开食品校招.cmd`；失败时检查 `server-error.log`。
- 同步失败：仍可浏览缓存；恢复联网后点击“立即更新”。
- 端口2027被其他程序占用：启动程序报错，不会终止其他应用。
- 取消开机启动：在 Windows“启动应用”中禁用，或删除当前用户启动目录中的 `FoodCampus2027.lnk`。
- 取消Codex每日更新：在Codex自动任务里暂停“食品行业2027校招每日更新”。
- 停止网站服务：在任务管理器“详细信息”查看命令行，仅结束运行本目录 `server.py` 的Python进程。不要批量终止其他Python任务。
